# SIACS-Sistema-Informacion-Asociaciones-Culturales-Santurtzi
Diseño y desarrollo de una aplicación web MVP orientada a la digitalización, gestión y análisis de datos de las asociaciones culturales del municipio de Santurtzi (Bizkaia). Objetivo: transformar información dispersa en conocimiento útil, mejorar la eficiencia administrativa y promover una gestión cultural basada en datos.
