# Validación de esta publicación

Fecha: 10/10/2026.

- Se ejecutó el ejemplo Python desde fuera del directorio del repositorio, reproduciendo el uso con un directorio de trabajo distinto en Spyder.
- Se cargaron el esquema y los datos SQL en SQLite en memoria con claves foráneas activadas. Las consultas de verificación, ejecución, ocupación y coste coincidieron con los cálculos Python.
- Se verificaron los casos sin registros, sin asistentes informados y con cero asistencias. Los resultados sin denominador se mantienen como no calculables.
- Se verificó que los enlaces relativos de Markdown apuntan a archivos existentes y que las cinco capturas son PNG decodificables.

El SQL está escrito con construcciones compatibles con PostgreSQL, pero no se ejecutó contra un servidor PostgreSQL en esta revisión. La validación del ejemplo no equivale a pruebas del MVP alojado ni de una implantación municipal.
